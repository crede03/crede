About This Website

Welcome to CREDE.VIP — my portfolio website and quiet corner of the internet. There's no Meta Pixels to track you here!

I wanted my portfolio to be a reflection of me - versatile, nostalgic, and, at times, unstable. So, naturally, I had to base it off Windows Vista!

This website is made possible thanks to these open-source projects, recreations, and web standards:

Paint.JS (JS Paint) GitHub ↗
A web-based remake of classic MS Paint featuring progressive web app support, session history, image formats, and modern accessibility tools.
By Isaiah Odhner · jspaint.app
Webamp GitHub ↗
A faithful in-browser reimplementation of Winamp in HTML5 and JavaScript using the Web Audio API with equalizer, playlist, and skin support.
By Jordan Eldredge · webamp.org
Clippy.JS GitHub ↗
Nostalgic (or annoying) desktop assistant bringing back Microsoft Agent animations, sound effects, and conversational prompts right on the web desktop.
Created by Smore / pi0 / pithings · github.com/pithings/clippy
7.css GitHub ↗
CSS framework recreating the authentic Windows 7 / Vista Aero Glass look, window frames, tabs, and desktop controls.
By khang-nd · github.com/khang-nd/7.css
Retro Screensavers WebGL / 2D Canvas
Custom real-time rendering engines reproducing the 3D FlowerBox (OpenGL), 3D Starfield warp simulation, and Matrix digital rain.
Web Audio Sound Engine Web Audio API
Synthesizer and sound fx pipeline for authentic Windows startup chime, window click, navigation, and minimize sound effects.
